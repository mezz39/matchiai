# Main Journey: Analysis

| # | Step (as written) | Input | Output |
|---|---|---|---|
| 1 | CV gaps analysis ("formats, results showing") | CV upload; target role info from step 2 *(added)* | Gap report showing missing or weak skills and sections, presented in clear formats (list, summary, visual) |

| 5 | Testing in Q/A form | CV uploaded | Questions and answers that clarify how well the user really knows their CV, honestly |
| 6 | Tracking progress to the goal | CV uploaded, plus updates on skills | Visualized progress showing where the user is in the journey toward the goal |
| 7 | Learning recommendations to advance to a target | Gaps from step 1, target info, current progress *(added)* | A clear curriculum to follow and apply for learning |
